# A* — поиск пути на карте проходимости

Прямоугольная карта, каждая клетка имеет степень проходимости от 0
(стена, непроходимо) до 1 (максимально проходимо). Нужно найти
близкий к оптимальному путь между двумя точками либо установить, что
пути не существует.

## Модель

- Движение по 8 направлениям (включая диагонали).
- Стоимость шага в клетку = `1 / проходимость_клетки`, диагональный
  шаг дополнительно умножается на `√2`.
- Во время поиска визуализируются раскрытые (просмотренные) клетки —
  видно, как A* исследует карту, — а затем итоговый путь.

## Формат карты (текстовый файл)

Одна строка файла - одна строка карты:

- `' '` (пробел) — максимально проходимо (1.0)
- `'0'` — стена, непроходимо
- `'1'..'9'` — пониженная проходимость (цифра / 10)

Пример — `maps/sample.txt`.

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Управление

- **ЛКМ** по клетке - поставить старт
- **ПКМ** по клетке - поставить финиш
- **ENTER / SPACE** - запустить поиск пути
- **R** - сгенерировать новую случайную карту
- **L** - загрузить карту из `maps/sample.txt`
- **C** - очистить визуализацию поиска (карта и точки остаются)
- **ESC** - выход


## Файлы

- `config.py` - параметры 
- `grid.py` - загрузка карты из файла и генерация случайной карты
- `astar.py` - алгоритм A* (пошаговый генератор для
  визуализации + синхронная обёртка)
- `main.py` - визуализация и обработка ввода на Pygame
