# Машинки — имитационное моделирование транспортного потока

Однополосный участок дороги. Машинки создаются в начале дороги через
случайные интервалы времени (показательное распределение), едут с
собственной желаемой скоростью (гауссовское или равномерное
распределение — переключается в `config.py`), тормозят при сближении с
лидером и разгоняются, когда дорога впереди свободна. По достижении
конца дороги машинка удаляется.

Клавиша **SPACE** резко тормозит случайную машинку из средней зоны
дороги на несколько секунд, чтобы спровоцировать устойчивую пробку —
после отпускания она снова едет по обычным правилам, а идущие следом
машинки тем временем вынуждены притормаживать, формируя затор.

Клик **левой кнопкой мыши** по машинке показывает её текущую скорость
(в м/с и км/ч) во всплывающей подсказке над ней.

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Файлы

- `config.py` - все параметры модели
- `car.py` - модель одной машинки (правила разгона/торможения)
- `simulation.py` - генерация машинок, поддержание порядка на дороге,
  триггер пробки
- `main.py` - визуализация на Pygame и обработка ввода
